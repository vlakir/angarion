# Vendored UI assets

Сторонние ассеты Web UI (§12.6), включённые в пакет и отдаваемые через
`StaticFiles` по `/ui/static/*`. Внешние CDN **не используются** — UI
обязан работать в офлайн/ограниченной сети. Файлы не редактируются
вручную; обновление — заменой на новую минифицированную версию upstream.

| Файл | Проект | Версия | Лицензия | Upstream |
|---|---|---|---|---|
| `pico.min.css` | Pico CSS | 2.1.1 | MIT | https://picocss.com |
| `htmx.min.js` | htmx | 2.0.10 | BSD 2-Clause | https://htmx.org |

Лицензии MIT / BSD 2-Clause разрешают распространение в составе пакета
при сохранении текста лицензии — см. upstream-репозитории проектов.
