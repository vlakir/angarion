# Пример: зеркало с медиа + доступ процессора к скачанному файлу

Сценарий angarion на Telegram (M7, часть A): новое сообщение из группы
**A** (источник) пересылается в группу **B** (цель) **вместе с вложением**,
а кастомный процессор `media_note` **читает скачанный файл** и добавляет его
метаданные (фактический размер на диске, локальный путь) в подпись.

Показывает целевой сценарий медиа-части ТЗ: при `[media] download = true`
принимающий аккаунт скачивает вложение при ingest и проставляет
`MediaRef.local_path`, а процессор работает с локальным контентом — не
только с метаданными.

> Базовая пересылка медиа работает и **без** этого примера (см.
> `examples/forward` — `passthrough` + fast-path по ссылке). Здесь нового
> два: **скачивание** (`[media] download`) и **процессор, читающий файл**.

## Что нужно

- Установленный проект с extra: `uv sync --extra telegram --extra sqlite`
  (или `uv add "angarion[telegram,sqlite]"` во внешнем проекте).
- Telegram-аккаунт, **состоящий в обеих группах** A и B.
- `api_id` / `api_hash` — с <https://my.telegram.org> → API development
  tools (или официальные TDesktop-ключи).
- `id` групп (вида `-100…`) — например, переслав сообщение из группы боту
  `@username_to_id_bot`, либо из клиента.

## Настройка

1. Подставь `id` групп в [`app.toml`](app.toml) (`sources` / `targets`).
2. Задай секреты в окружении (не в файлах — они не должны попасть в git):

   ```bash
   export ANGARION_ACCOUNTS__MAIN__API_ID=12345
   export ANGARION_ACCOUNTS__MAIN__API_HASH=0123456789abcdef0123456789abcdef
   ```

## Запуск

```bash
examples/media/run.sh
```

Скрипт «всё в одном» (идемпотентный): генерирует ключ шифрования сессии,
применяет миграции, при первом запуске авторизует аккаунт (телефон → код →
2FA), затем запускает конвейер через `run.py` (регистрирует процессор
`media_note`).

Проверка: пришли в группу A фото/видео/документ — в B прилетит то же
вложение с подписью вида `📥 переслано с медиа / <текст> / 📎 photo «…» —
NNNNN Б на диске (angarion-data/media/…)`. В логе — событие `media_seen`
с `local_path` и `on_disk_bytes`.

`Ctrl+C` — корректная остановка.

## Как это устроено

- **`[media] download = true`** ([`app.toml`](app.toml)) — принимающий
  аккаунт скачивает подходящие вложения (`allowed_kinds`, `max_size`) в
  `storage_dir` при ingest и проставляет `MediaRef.local_path`.
- **`media_note`** ([`media_processor.py`](media_processor.py)) — на событии
  с медиа читает фактический размер файла по `local_path` (доступ к
  контенту) и собирает подпись; вложение переносит транзитом через
  `OutboundRecord.media`. Sender при наличии `local_path` грузит файл
  напрямую (работает и кросс-аккаунт); без него — fast-path по ссылке.
- **Ретеншн.** `retention_days` + `[worker] prune_interval` — фоновая
  prune-задача удаляет скачанные файлы старше срока. `storage_dir =
  angarion-data/media` git-ignored, диск не растёт бесконтрольно.

## Заметки

- Весь рантайм (БД, ключ, сессия, **скачанные файлы** в
  `angarion-data/media/`) — в `angarion-data/` рядом со скриптом; каталог в
  `.gitignore`, секреты и контент в репозиторий не попадают.
- Пересылается только `new`. Кросс-аккаунт (источник и цель на
  **разных** аккаунтах) тоже работает благодаря скачиванию — здесь для
  простоты один аккаунт в двух группах.
- `queue = "memory"`: при `Ctrl+C` необработанное в очереди теряется, но
  catch-up доберёт на следующем `run`. Для боевого режима —
  `backend = "persistqueue"` (extra `persistqueue`).

## Если код авторизации не приходит

`angarion login` запрашивает код у Telegram; **канал доставки выбирает
Telegram**. Из-под VPN код может уйти не в приложение, а по SMS/звонку.
Если кода нет: проверь служебный чат **Telegram** (`777000`), SMS и звонки;
попробуй без VPN и/или при доступной сотовой сети.
