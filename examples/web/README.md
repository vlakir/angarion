# Пример: конвейер + Web API/UI с кастомной ручкой и страницей

Боевой сценарий angarion в **combined-режиме** (конвейер + встроенный
Web-адаптер в одном процессе, аналог `angarion run --with-api`),
расширенный **своей JSON-ручкой и своей UI-страницей** поверх портов.

Демонстрирует:

- встроенный Web UI — дашборд `/ui`, граф топологии `/ui/pipelines`
  (серверный SVG), журнал аналитики `/ui/events`;
- расширение через DI поверх портов ([`ext.py`](ext.py)): ручка
  `GET /api/v1/ext/stats` (счётчики аналитики за сутки) и страница
  `/ui/ext` «Activity», получающие `AnalyticsPort` типизированной
  зависимостью `AnalyticsDep` — без знания об ORM/сессиях/Telethon;
- собственный composition root ([`run.py`](run.py)): `build_app` +
  `build_web_deps` + `create_app(routers=…, pages=…)` + uvicorn рядом с
  конвейером.

Конвейер под капотом — тот же `passthrough` A→B, что в
[`../forward`](../forward): нужен он только чтобы наполнять аналитику,
которую показывает Web UI.

## Почему свой лаунчер, а не чистый `--with-api`

UI-**страницы** (`pages`) с T029 подхватываются чистым CLI: установленный
пакет регистрирует `Page` в entry-point-группе `angarion.pages`, и
`angarion run --with-api` (а также `--role api`) монтирует их в навигацию
без своего лаунчера. А вот пользовательские JSON-**`routers`** передать
через CLI по-прежнему нельзя (Python-объект мимо конфигурации).

Этот пример показывает **и ручку (router), и страницу** одним процессом,
поэтому подключает их собственным лаунчером `run.py`, который зовёт
`create_app(deps, routers=[…], pages=[…])`. Это поддерживаемый путь
расширения (см. [`docs/guides/web-api.md`](../../docs/guides/web-api.md)).
Если расширение — только страница (без своей JSON-ручки), лаунчер не
нужен: достаточно entry point `angarion.pages`.

## Что нужно

- Установленный проект с extra:
  `uv sync --extra telegram --extra sqlite --extra web`
  (или `uv add "angarion[telegram,sqlite,web]"` во внешнем проекте).
- Telegram-аккаунт, **состоящий в обеих группах** A и B.
- `api_id` / `api_hash` — с <https://my.telegram.org> → API development
  tools.
- `id` групп (вида `-100…`) — например, переслав сообщение из группы боту
  `@username_to_id_bot`, либо из клиента.

## Настройка

1. Подставь `id` групп в [`app.toml`](app.toml) (`sources` / `targets`).
2. Задай секреты в окружении (не в файлах — они не должны попасть в git):

   ```bash
   export ANGARION_ACCOUNTS__MAIN__API_ID=12345
   export ANGARION_ACCOUNTS__MAIN__API_HASH=0123456789abcdef0123456789abcdef
   ```

## Запуск

```bash
examples/web/run.sh
```

Скрипт «всё в одном» (идемпотентный): генерирует ключ шифрования сессии,
применяет миграции, при первом запуске — интерактивная авторизация
(`angarion login`), затем поднимает combined-процесс через `run.py`.

После старта открой:

- <http://127.0.0.1:8000/ui> — дашборд (+ навигация на граф, события и
  страницу примера «Activity»);
- <http://127.0.0.1:8000/ui/ext> — кастомная страница;
- <http://127.0.0.1:8000/api/v1/ext/stats> — кастомная JSON-ручка.

Напиши в группу A — сообщение пролетит в B, а счётчики на `/ui/ext`
обновятся. `Ctrl+C` — корректная остановка всего процесса.

Весь рантайм (БД, ключ, сессия) — в `angarion-data/` рядом со скриптом;
каталог в `.gitignore`, секреты в репозиторий не попадают.

## Заметки

- `[api].auth = "none"` — локальный режим: все роутеры открыты под
  синтетическим админом, без user store и JWT-секрета. Для публичного
  доступа — `auth = "users"` за TLS-прокси (см.
  [`docs/guides/deploy.md`](../../docs/guides/deploy.md) и
  [`web-api.md`](../../docs/guides/web-api.md)).
- Bind строго на `127.0.0.1`: при `auth = "none"` и не-локальном bind
  адаптер пишет громкое предупреждение в лог.
- Своя ручка из `routers=[…]` монтируется под `CurrentUser` (как
  встроенный `/api/v1`); страницу можно осознанно открыть —
  `Page(…, public=True)`.
- `queue = "memory"`: при `Ctrl+C` необработанное в очереди теряется, но
  catch-up доберёт на следующем `run` (storage в sqlite персистентный).

## Если код авторизации не приходит

`angarion login` запрашивает код у Telegram; **канал доставки выбирает
Telegram**. Из-под VPN код может уйти не в приложение, а по SMS/звонку.
Проверь служебный чат Telegram (`777000`), SMS и звонки; попробуй без VPN.
