# Пример: пересылка сообщений из одной группы в другую

Минимальный боевой сценарий angarion на Telegram: live-сообщения из
группы **A** (источник) ретранслируются в группу **B** (цель) встроенным
процессором `passthrough`.

Демонстрирует полный конвейер на реальном аккаунте: listener (MTProto) →
ingest → очередь → worker → sender, через CLI `angarion`.

## Что нужно

- Установленный проект с extra: `uv sync --extra telegram --extra sqlite`
  (или `uv add "angarion[telegram,sqlite]"` во внешнем проекте).
- Telegram-аккаунт, **состоящий в обеих группах** A и B.
- `api_id` / `api_hash` — с <https://my.telegram.org> → API development
  tools (или официальные TDesktop-ключи).
- `id` групп (вида `-100…`) — узнать можно, например, переслав сообщение
  из группы боту `@username_to_id_bot`, либо из клиента.

## Настройка

1. Подставь `id` групп в [`app.toml`](app.toml) (`sources` / `targets`).
2. Задай секреты в окружении (не в файлах — они не должны попасть в git):

   ```bash
   export ANGARION_ACCOUNTS__MAIN__API_ID=12345
   export ANGARION_ACCOUNTS__MAIN__API_HASH=0123456789abcdef0123456789abcdef
   ```

## Запуск

```bash
examples/forward/run.sh
```

Скрипт «всё в одном» (идемпотентный):

1. генерирует ключ шифрования сессии в `angarion-data/session.key`
   (один раз, переиспользуется);
2. применяет миграции БД (`angarion-data/app.db`);
3. при первом запуске — интерактивная авторизация (`angarion login`:
   телефон → код из Telegram → 2FA), дальше пропускается;
4. запускает конвейер (`angarion run`).

Проверка: после старта напиши в группу A — текст прилетит в B.
`Ctrl+C` — корректная остановка.

Весь рантайм (БД, ключ, сессия) — в `angarion-data/` рядом со скриптом;
этот каталог в `.gitignore`, секреты в репозиторий не попадают.

## Заметки

- **Медиа пересылается из коробки.** `passthrough` переносит вложения
  транзитом, sender переотправляет их по платформенной ссылке (fast-path,
  без скачивания) — фото/видео/документ из A долетают в B вместе с текстом.
  Управление скачиванием/хранением (нужно для кросс-аккаунт доставки и
  доступа процессора к файлу) — глобальная секция `[media]` (см. README
  проекта, раздел «Медиа»); здесь, при одном аккаунте, скачивание не нужно.
- Пересылается только `new`. Чтобы ловить правки/удаления —
  добавь `"edited"`, `"deleted"` в `events` (на удалении
  `passthrough` ничего не шлёт — текста для пересылки нет).
- `queue = "memory"`: при `Ctrl+C` необработанное в очереди теряется, но
  catch-up доберёт на следующем `run` (storage в sqlite персистентный).
  Для боевого режима — `backend = "persistqueue"` (extra `persistqueue`).
- Своё пересланное сообщение в группе B твой же аккаунт «новым» не
  увидит, а статус прочтения источника адаптер не меняет (наблюдатель) —
  это семантика пользовательского аккаунта, не баг.

## Если код авторизации не приходит

`angarion login` запрашивает код у Telegram; **канал доставки выбирает
Telegram**. Из-под VPN (запрос с «чужого» IP) код может уйти не в
приложение, а по SMS/звонку на номер. Если кода нет:

- проверь служебный чат **Telegram** (`777000`), SMS и входящие звонки;
- попробуй без VPN и/или при доступной сотовой сети.
