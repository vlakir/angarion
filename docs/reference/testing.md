# Контрактные тесты

Публичные контрактные наборы тестов портов (§12.11 ТЗ) — сертификационный
инструмент автора стороннего адаптера/хранилища. Параметризуйте классы
своей реализацией (fixture-override) и добейтесь зелёного прогона.

Требует extra `angarion[testing]` (pytest + pytest-asyncio). Walkthrough —
в [гайде автору плагина](../guides/plugin-authoring.md#сертификация-контрактными-тестами).

::: angarion.testing
